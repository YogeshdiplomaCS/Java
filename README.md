# Java

A beginner-friendly collection of Java practice code and small projects covering programming fundamentals, object-oriented programming, and problem solving.

## Requirements

- Java Development Kit (JDK)
- A terminal or Java IDE such as IntelliJ IDEA, Eclipse, or NetBeans

Check your installation with:

```bash
java -version
javac -version
```

## Compile and run a standalone example

Open a terminal in the folder containing a Java source file. For a file whose public class is named `Example`, compile and run it with:

```bash
javac Example.java
java Example
```

The Java filename must match its public class name. If a source file declares a package, compile and run it from the appropriate source root. Follow any project-specific instructions when present.

## Suggested repository organization

Group examples by topic (for example, `basics/`, `oop/`, `data-structures/`, and `projects/`) and give each example a descriptive name. Include sample input/output for exercises where it helps.

## Learning and contributions

Try the examples, change them, and add your own solutions. For each larger project, document its purpose, how to run it, and any database or other setup it needs. Add tests as projects grow.
